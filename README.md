# Khata GST Accounting

Accounting and GST software for small businesses in India: sales, purchases,
bank entries, stock, credit and debit notes, GSTR-1 and GSTR-3B JSON, Tally export.
Works for regular, composition and unregistered businesses.

## Download
Get the latest installer from the Releases page:
https://github.com/Zahidmsn/Khata-GST-Accouting/releases/latest

## Install (Windows 10 or 11)
1. Download the file ending in .exe and double-click it.
2. If Windows says "Windows protected your PC", click More info, then Run anyway.
3. Follow the installer and open Khata.
4. The first screen shows your Device ID. Send it to us.
